Solside 0.1.1 for Windows x64.

- Light and Dark appearance options in Settings, remembered between launches.
- Version number in the window title.
- Developer Edition banner and separate development profile.

Download **Solside-Setup-x64.exe** and run it. The installer is unsigned, so Windows may display a publisher warning. SHA256SUMS.txt contains its checksum.

This version does not include in-app update checks. The automated build verifies compilation, packaging, and the uploaded installer's checksum; it does not verify installation or upgrades on a clean Windows system.
